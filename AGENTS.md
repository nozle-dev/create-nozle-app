# Agent instructions

## Versioning

Every pull request bumps the version of each template it changes (`<template>/package.json`) in the same PR: patch for a fix or a refactor, minor for a feature or a visible change, major for a breaking change. Stacked PRs bump in order. Put the new version in the PR description and state the bump (for example `1.0.0 → 1.0.1`).
